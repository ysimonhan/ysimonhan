## Engineering Principles

- Start from the workflow, not the model.
- Keep tools, orchestration, business rules, and UI concerns separated.
- Use synthetic or sanitized data for public demos.
- Prefer simple deployed systems over impressive but fragile prototypes.
- Document architecture decisions so future humans and agents can resume work cold.
